## 编写约定

1. 各章采用独立 Markdown 文件，文件名前缀与章节编号一致。
2. `api` 仅表示 HTTP/WebSocket 接口处理层，不使用 `controller` 指代 API Handler。
3. `Controller` 表示设备控制、任务执行和协同控制相关的内部控制逻辑。
4. `Communication` 统一承载 HTTP、WebSocket、TCP 和 UDP 通信能力。
5. 数据库模块统一命名为 `db`，认证与授权模块统一命名为 `auth`，设备及外部系统适配模块统一命名为 `access`。
6. 公共基础能力统一归入 `core`，第三方依赖统一归入 `lib`。
7. 一期不引入 IOC，设备协同、状态管理和安全联锁由 Backend 统一实现。
